dns lookup

A name becomes a number

Networks route by IP address, not by name. To find example.com, the browser first checks answers it already remembers. If those miss, a recursive resolver walks the naming tree for it, from the root servers down to the domain’s own.

Press Resolve. The host name comes from the address you entered in scene 1.
