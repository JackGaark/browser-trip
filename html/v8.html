v8: from source to machine code

JavaScript gets faster the more it runs

Engines start by interpreting bytecode, which starts quickly but runs slowly. Code that runs often gets recompiled by faster tiers, which bet on the types they have seen. Break that bet and the engine bails out, or deoptimizes, back to the start.

Tiers are V8’s. Thresholds, speeds and the machine code shown are illustrative; real engines decide from runtime feedback.
