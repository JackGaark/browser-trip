layout

Every box gets a position and a size

With the DOM and CSS combined into computed styles, layout works out where each box goes and how big it is. Change the viewport width and the whole page gets recalculated. The page on the right is real HTML and CSS, and the numbers are measured live by your browser.

Below 430 px a container query stacks the columns; below 300 px the nav hides.
