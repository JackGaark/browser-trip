http/2: many streams, one connection

Ten files, one pipe

The HTML arrives first and names nine more files. HTTP/1.1 can carry only one response at a time per connection, so browsers open up to six connections per site, each with its own handshake, and queue the rest. HTTP/2 interleaves every file as streams over the one connection it already has.

Simulated with a 40 ms round trip and a 12 Mbps link. c1–c6 mark which HTTP/1.1 connection carried each file.
